# 🧠 Chat IA Local con Ollama (P022)

Aplicación web tipo ChatGPT construida con Flask + Ollama, que permite conversar con un modelo de IA local con streaming en tiempo real y guardado automático de conversaciones.

---

## 🚀 Características

- 💬 Interfaz tipo chat (estilo WhatsApp / ChatGPT)
- ⚡ Respuestas en streaming (en tiempo real)
- 🧠 Uso de modelos locales con Ollama
- 💾 Guardado automático de conversaciones
- 🧹 Botón para limpiar chat
- ⌨️ Envío con Enter
- 🎨 Diseño moderno y responsivo

---

## 🛠️ Tecnologías

- Python
- Flask
- Ollama
- HTML / CSS / JavaScript
